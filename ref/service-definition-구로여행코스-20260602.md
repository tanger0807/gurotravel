## 0. Executive Summary (한 장 요약)

**한 줄 정의**: 서울 시민이 구로구를 방문할 때, 인터랙티브 지도에서 장소를 클릭하면 해당 코스 정보(동선·예상 비용·스탬프 포인트)를 바로 확인할 수 있는 큐레이션 여행 웹페이지

**핵심 문제**: 오류동·항동에 독립서점 4곳·오류버들시장·푸른수목원·천왕산 책쉼터가 산재하지만 연결 동선이 없어, 방문객이 지역 상권에 실질 매출을 남기지 못하고 이탈

**우리 해결책**: 타깃 3개 × 지역(오류동·항동) × 테마 2개 코스 카드 + 장소 핀 클릭 인터랙티브 지도

**차별점**: 네이버 지도·블로그와 달리 — 지도 핀 클릭 → 코스 소개 팝업 + 예상 비용 + 스탬프 포인트까지 한 페이지에서 해결

**MVP 범위**: 인터랙티브 지도(핀 클릭 → 코스 상세) + 코스 카드 + 장소별 예상 비용

**필요 자원**: 1인 / 2일 / 비용 없음 (포트폴리오)

## 1. 한 문장 서비스 정의

서울 시민이 구로구(오류동·항동)를 방문할 때, 인터랙티브 지도에서 장소 핀을 클릭해 테마 코스(문학 기행·힐링)와 동선별 장소·예상 비용을 한눈에 확인할 수 있는 큐레이션 여행 웹페이지

---

## 2. 타깃 고객 (기획서 페르소나 반영 → 구체화)

### 2.1 타깃 A — 2030 책 애호가 1인 or 2인 (핵심 타깃)
- **누구**: 20~30대 여성, 인스타·블로그로 '요즘 독립서점' 콘텐츠 소비
- **상황**: 혼자 또는 친한 친구 1명과 "남들 안 가본 감성 동네 서점 + 자연 산책"을 하루에 묶고 싶은 주말
- **결정 트리거**: '남들 안 가본 서점' / '사진 잘 나오는 수목원' / '백종원이 다녀간 오류버들시장'
- **1인 예산**: 3.5~5.5만원 (책 1~2권 + 시장 식사 + 카페)
- **현재 행동**: 인스타그램 릴스·네이버 블로그 검색 → 여러 탭에서 직접 동선 조합

### 2.2 타깃 B — 2030 커플
- **누구**: 20~30대 커플, 색다른 데이트 코스를 원하는 사람
- **상황**: "또 홍대야?" 피하고 싶을 때, 분위기 있는 골목·카페·수목원 코스 원함
- **현재 행동**: 카카오맵 검색 → 장소 개별 저장 → 동선 비효율

### 2.3 타깃 C — 문학·자연을 좋아하는 4050세대
- **누구**: 40~50대, 역사·문학·자연 산책 선호, 가족 동반 나들이
- **상황**: 신영복 선생 더불어숲, 오규원 시인 스토리텔링 같은 문화적 의미 있는 장소 방문
- **현재 행동**: 구로구청 홈페이지·문화원 블로그 → 정보 파편화, 지도 연동 없음

## 3. 현재 문제와 기존 대안

### 3.1 문제 정의 (기획서 Before 반영)
오류동·항동에 독립서점 4곳(콕콕콕·비씨지북스·포옹단락·책방공책), 오류버들시장, 신영복 더불어숲, 푸른수목원, 천왕산 책쉼터가 산재하지만 연결 동선이 없다. 방문객은 개별 시설을 따로따로 방문하거나 무료 공공시설에서만 머물다 지역 상권에 실질 매출을 남기지 못하고 이탈한다.

### 3.2 기존 대안

| 대안 | 한계 |
|---|---|
| 네이버 지도 검색 | 장소 핀만 나열 — 테마별 연결 동선·예상 비용 없음 |
| 블로그·인스타그램 후기 | 최신 정보 불명확, 장소 단위 소개에 그침, 코스 전체 동선 없음 |
| 구로구청 공식 홈페이지 | 정보는 있으나 시각적으로 정리되지 않고 지도 연동·동선 안내 없음 |
| 동네서점 지도 사이트 (이미지 참고) | 서점 위치만 표시 — 코스 연결·예상 비용·스탬프 투어 기능 없음 |

## 4. 핵심 가치 제안

**Before**: "구로구 독립서점" 검색 → 블로그 3개·네이버 지도·구청 홈페이지를 따로 열어 직접 동선 조합 (30분 소요)

**After**: 지도에서 장소 핀 클릭 → 코스 소개 팝업(동선·체류 시간·예상 비용) → 바로 출발

핵심 변화: "흩어진 정보 직접 조합 30분 → 지도 핀 1번 클릭으로 코스 전체 파악"

## 6. 핵심 기능 정의 — 인터랙티브 지도 포함

### 6.1 기능 1 — 인터랙티브 지도 (신규 추가 · 핵심 기능)

**개념 설명 (비유)**: 종이 지도에 스티커 핀을 꽂아두고, 그 핀을 손가락으로 누르면 그 장소의 소개 카드가 펼쳐지는 것과 같다. 웹에서는 이걸 "마커 클릭 → 팝업(정보창) 표시"라고 부른다.

| 요소 | 내용 |
|---|---|
| 지도 범위 | 오류동역 ~ 항동 (구로구 서부) |
| 핀(마커) 표시 장소 | 11개 거점 (코스 5.1 전체) |
| 마커 색상 구분 | 🟢 독립서점 / 🟡 시장·카페 / 🔵 자연·문화 거점 |
| 클릭 시 팝업 내용 | 장소명 / 코스 순서 / 활동 한 줄 설명 / 체류 시간 / 예상 비용 / 스탬프 여부 |
| 구현 방식 | Kakao Maps API 또는 Naver Maps API (무료 사용 가능) — 정적 HTML+JS로 구현 |

**지도 위 동선 표시**: 마커 간 경로선(polyline) 표시로 코스 흐름을 한눈에 파악 가능하게 함.

### 6.2 기능 2 — 테마 탭 필터 (문학 기행 / 힐링)
- 탭 클릭 시 해당 테마의 마커와 코스 카드만 표시
- 기본값: 전체 보기

### 6.3 기능 3 — 코스 카드 (지역별)
- 오류동 카드 / 항동 카드 각 2개 (문학기행·힐링)
- 카드 내 포함 정보: 코스명 / 총 소요시간 / 1인 예상 비용 / 주요 타깃 배지 / 장소 목록

### 6.4 기능 4 — 장소별 상세 정보 (스탬프 투어 연동)
- 독립서점 4곳에 스탬프 아이콘 표시
- "4곳 모두 방문 시 엽서 세트 증정" 스탬프 투어 안내 포함

### 6.5 기능 5 — 반응형 레이아웃
- 모바일 우선 (여행 중 현장에서 보는 용도)
- 지도·카드 모두 모바일에서 깨짐 없이 동작

## 8. MVP 기능 범위

### 8.1 포함 기능 (2일 내 구현 가능)

| # | 기능 | MVP 필수 이유 |
|---|---|---|
| 1 | 인터랙티브 지도 (핀 클릭 → 코스 팝업) | 서비스의 핵심 UX — 지도 없으면 차별점 없음 |
| 2 | 마커 색상 구분 + 동선 경로선 | 코스 흐름을 지도에서 직관적으로 파악 |
| 3 | 테마 탭 필터 (문학기행·힐링) | 타깃별 코스 선택의 핵심 인터랙션 |
| 4 | 코스 카드 (장소·예상비용·타깃 배지) | 지도 클릭 전 코스 전체 조망 |
| 5 | 반응형 (모바일 우선) | 현장에서 보는 용도 — 모바일 필수 |

### 8.2 제외 범위 (v1에서 안 함)

- 실시간 영업시간 API 연동 — 정적 정보로 대체, 방문 전 확인 안내
- 스탬프 디지털 인증 — 실물 스탬프북 안내 텍스트로 대체
- 회원가입·즐겨찾기 — 포트폴리오 단계 불필요
- 온수동 코스 콘텐츠 — 2일 내 데이터 확보 어려움, 와이어프레임으로 제출
- AI 맞춤 코스 생성 — v2 보류

## 다음 단계 입력 요약본 (Handoff Pack)

### 1. 한 줄 정의
서울 시민이 구로구(오류동·항동)를 방문할 때, 인터랙티브 지도에서 장소 핀을 클릭해 테마 코스(문학기행·힐링)·동선·예상 비용을 한눈에 확인할 수 있는 큐레이션 여행 웹페이지

### 2. 잠긴 결정
- **타깃**: 2030 독립서점 애호가(핵심) / 2030 커플 / 4050 문학·자연 선호자
- **지역**: 오류동 + 항동 (온수동은 v2)
- **핵심 기능**: 인터랙티브 지도 (Kakao Maps API) + 마커 클릭 팝업
- **코스 데이터**: 11개 거점, 1인 55,000원, 7~8시간 (답사 확정 데이터)
- **테마**: 문학 기행 / 힐링 2개
- **수익 모델**: 없음 (포트폴리오)

### 3. 미해결 / 추후 결정
- Kakao Maps API vs Naver Maps API 최종 선택 — PRD 단계에서 결정
- 온수동 코스 콘텐츠 — 2일 내 데이터 확보 어려움, 와이어프레임으로 우선 제출
- 지도 마커 이미지 디자인 (색상·아이콘) — 디자인 시스템 단계에서 결정

### 4. PRD 작성 시 핵심 변수
- 서비스명: 구로 여행코스 (가칭)
- 1순위 타깃: 인스타·블로그로 독립서점 탐방하는 2030 여성 1~2인
- 핵심 문제: 오류동·항동 거점 산재 + 연결 동선 부재
- 가치 제안: 지도 핀 클릭 1번 → 코스 전체(동선·비용·스탬프) 파악
- MVP 기능: 인터랙티브 지도 / 마커 클릭 팝업 / 테마 탭 / 코스 카드 / 반응형
- 코스 데이터: 11개 거점 (오류버들시장·독립서점4곳·더불어숲·푸른수목원·책방공책·그리니치카페·항동철길·천왕산책쉼터)
- KPI: 지도 11핀 팝업 동작 + 코스카드 4개 완성 + 2일 내 제출
